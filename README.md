# AI STV — bootstrap

Repo này chỉ chứa **bootstrap.sh**. Toàn bộ mã nguồn nằm ở repo riêng tư `Phucvncom55/AISTV`.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Phucvncom55/aistv-boot/main/bootstrap.sh)
```

Cần token GitHub đọc được repo riêng tư (fine-grained PAT, quyền **Contents: Read**), đặt một lần vào 🔑 Colab Secrets với tên `GITHUB_TOKEN` — các lần sau không phải nhập lại.
